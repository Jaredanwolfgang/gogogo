# 桌面操作录屏

[观看视频](../results/desktop-demo.mp4) · [中文字幕](../results/desktop-demo.srt)

成片长 1 分 50 秒，H.264 / MP4，1600×1226，30 fps，无音轨。使用 macOS `screencapture -v -l窗口ID` 直接捕获 GOGOGO 的 Tkinter 窗口，所有落子与指令通过桌面键盘输入，重开和认负通过系统确认对话框完成。原始录制约 140 秒；导出时保留前 110 秒，裁去窗口外围黑边，不重绘游戏画面。

## 复录

```sh
python3.12 main.py --gui
# 取得当前游戏窗口 ID 后运行，录制 140 秒并自动保存：
sh scripts/record_desktop.sh 窗口ID /tmp/gogogo-desktop.mov 140
```

macOS 需为启动命令的宿主应用授予录屏权限。按窗口 ID 捕获，不使用全屏或桌面矩形录制；窗口重新创建后须重新取得 ID。请等待倒计时自动完成，提前发送 Ctrl-C 可能使系统丢弃尚未写出的文件。

底部输入框输入命令后按 Enter。Tab 可切换控件，空格可触发获得焦点的按钮。重新开始和认负需要确认。本片验证的是键盘命令交互与确认对话框；没有把棋盘鼠标落子作为已验证项。

围棋提子序列：`new go 8`，然后 `play 1 2`、`play 1 1`、`play 8 8`、`play 7 7`、`play 2 1`。再执行 `play 1 1` 展示禁自杀，`undo` 恢复白棋，`play 2 1` 重新提子。`save results/desktop-save.json` 保存；重开并读取该文件后，棋盘、提子数、历史与剩余悔棋次数一致。

工具栏游戏和尺寸选择框用于准备下一局；当前游戏与大小以棋盘右侧状态为准。

原 `results/demo.mp4` 保留为 3 分 44 秒的命令输出回放，另含劫争和悔棋额度等场景。它与本次真实窗口录屏使用不同文件名。
